How to upload

  1. Register or log in.
  2. Click the Upload button.
  3. Enter the required information.
  4. Upload the bot data.
    First, export your bot from the game as a .bot file. In the Garage, select Prefabs → Local Export, then select the bot you want to export. After exporting, check the templates folder:
    C:\Users\%user%\AppData\LocalLow\Ironshell Studios\Procelio\templates
  5. Upload the thumbnail image and preview images. (Preview images are optional.)

How to import to game

  1. Click the About button for the robot you want to import on this page, then select Download. Save the displayed text.
  2. Place the downloaded file in the templates folder.
    C:\Users\%user%\AppData\LocalLow\Ironshell Studios\Procelio\templates
  3. Append the displayed text from the Download dialog to the index.file in the templates folder.
  4. In the Garage, select Prefabs, then move the Garage slots all the way to the right. The added bot will be there.
